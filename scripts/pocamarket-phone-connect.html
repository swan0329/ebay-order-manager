포카마켓 휴대전화 연결

어려운 명령어는 입력하지 않아도 됩니다. 휴대전화 화면에 보이는 숫자만 아래에 옮겨 적으세요.

무선 디버깅을 다시 켰나요?

같은 Wi-Fi에 연결한 뒤 아래 버튼을 누르세요. 저장된 주소와 새 무선 포트를 찾아 기존 대기 요청을 이어갑니다. 결제 확인 대기·실패 작업은 자동 재구매하지 않습니다.

주문 화면 열기
연결 상태 확인 중…
1

처음 한 번만 페어링

휴대전화에서 설정 → 개발자 옵션 → 무선 디버깅 → 페어링 코드로 기기 페어링을 누르세요.

2

휴대전화 연결

페어링 창을 닫고 무선 디버깅 메인 화면으로 돌아가세요. 거기에 보이는 IP 주소 및 포트를 입력합니다.

중요: 1번의 페어링 포트와 2번의 연결 포트는 서로 다릅니다. 주소 전체를 다시 확인해 주세요.

3

주문 화면에서 대기 작업 확인

상단 상태가 초록색 ‘구매 준비 완료’가 되면 기존 대기 요청이 자동으로 진행됩니다. 요청을 다시 만들지 말고 주문 화면의 진행 상태를 확인하세요. 결제를 끝낸 뒤 ‘휴대폰 결제 1장 완료’를 눌러야 다음 장이 준비됩니다. 결제 비밀번호와 생체 인증은 휴대전화에서 직접 확인합니다.
