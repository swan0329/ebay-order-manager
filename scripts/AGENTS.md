# 로컬 작업자와 관리 스크립트

## 범위

이 디렉터리는 포카마켓 Android 연결, 이미지 특징·마스크 생성, 상품 가져오기, 관리자 비밀번호 설정처럼 서버 밖에서 명시적으로 실행하는 작업을 소유한다. 웹 요청 처리와 운영 데이터 구조 변경은 소유하지 않는다.

## 규칙

- 포카마켓 연결은 본인 기기와 계정만 사용하고 결제 인증을 자동 입력하지 않는다.
- 화면 문구·상품번호·가격 상한을 확인하지 못하면 멈춘다. 좌표를 추측하거나 무한 재시도하지 않는다.
- 로컬 설정, 전용 토큰, 기기 식별정보, 통신 원본과 결제정보를 커밋하거나 일반 로그에 남기지 않는다.
- 대량 변경 스크립트는 대상 수와 미리보기를 먼저 보여주고 재실행해도 결과가 중복되지 않게 한다.
- 이미지 생성 스크립트는 원본을 덮어쓰지 않고 결과 경로와 생성 조건을 기록한다.

## 검증

쓰기 없는 점검 모드, 기기 없음·여러 기기, 화면 변경, 가격 초과, 서버 통신 실패, 사용자 인증 대기 시간을 확인한다. 대량 스크립트는 작은 표본과 백업으로 먼저 실행한다.
