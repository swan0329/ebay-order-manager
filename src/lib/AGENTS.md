# 업무 로직과 외부 연결

## 범위

이 디렉터리는 상품·주문·재고·가격·등록 초안·이미지 작업과 eBay·Shopify·R2 연결의 처리 순서를 소유한다. 화면 구성과 데이터 구조 배포는 소유하지 않는다.

## 경계와 불변 조건

- 재고 변경은 수량, 이동 이력, 주문 항목 차감 표시가 서로 어긋나지 않게 처리한다. 재고를 직접 갱신하는 우회 경로를 추가하지 않는다.
- SKU 자동 연결과 이미지 유사도는 후보를 만들 수 있지만 사람의 확정 결과를 덮어쓰지 않는다.
- 포카마켓 구매, 이미지 채택, 계산 가격 게시에는 승인 상태를 확인한다.
- 외부 쓰기는 내부 작업 ID와 외부 ID를 보존하고 재시도 전에 기존 성공 여부를 확인한다.
- 서버 전용 자격증명과 복호화된 토큰을 반환값, 브라우저 번들, 일반 로그에 포함하지 않는다.
- 요청 중 데이터 구조를 만드는 새 코드를 추가하지 않는다. 필요한 구조는 마이그레이션으로 요청한다.

## 테스트

순수 계산은 네트워크 없이 단위 테스트한다. 재고 0, 중복 차감, 취소 복구, 수수료 합계 100% 이상, 포카마켓 품절·가격 상승, 외부 성공 뒤 내부 응답 실패, 이미지 승인·거절을 경계 사례로 포함한다.
