# 화면과 요청 처리

## 범위

이 디렉터리는 관리자·작업자 화면, 서버 렌더링, `/api` 요청의 입력·응답을 소유한다. 재고 계산, 가격 공식, 외부 등록 순서, 이미지 승인 규칙 자체는 소유하지 않으며 `src/lib`에 위임한다.

## 경계와 규칙

- 페이지는 데이터 접근 전에 관리자 또는 작업자 역할을 확인한다. API는 UI 표시 여부와 무관하게 서버에서 다시 확인한다.
- 작업자 경로는 배정된 이미지 작업 외의 주문·가격·재고·판매 계정 데이터를 반환하지 않는다.
- 외부 입력은 요청 경계에서 검증한다. 오류 응답에는 안전한 설명만 넣고 토큰·원본 외부 오류·구매자 정보를 포함하지 않는다.
- 한 요청에서 부분 성공이 위험한 재고·구매·등록 작업은 업무 서비스의 원자적 또는 재시도 안전 경로만 호출한다.
- Next.js 동작을 바꾸기 전에 설치된 `node_modules/next/dist/docs/`의 해당 문서를 읽는다.

## 검증

관리자 성공, 작업자 성공, 역할 불일치, 미로그인, 잘못된 입력, 대상 없음, 외부 실패를 확인한다. 쓰기 요청은 같은 입력을 재시도했을 때 중복 재고 차감·구매·게시가 생기지 않는지도 확인한다.
