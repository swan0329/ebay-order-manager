# 데이터 구조

## 범위

이 디렉터리는 PostgreSQL 스키마, seed, 배포 가능한 변경 이력을 소유한다. 화면별 임시 데이터 가공이나 외부 API 호출은 소유하지 않는다.

## 규칙

- 기존 운영 데이터를 보존하는 순방향 마이그레이션을 추가한다. 적용된 마이그레이션을 고쳐 쓰지 않는다.
- 주문·상품·재고 이력의 외래키 삭제 동작을 바꿀 때 보존 결과를 명시적으로 확인한다.
- 금액은 부동소수점이 아닌 Decimal로 저장하고 통화·환율·계산 당시 설정을 구분한다.
- 승인·구매·외부 게시 작업은 중복 방지 키, 상태, 생성·완료 시각, 실패 정보를 저장한다.
- 런타임 SQL로 만든 기존 테이블을 편입할 때 실제 열·인덱스·데이터를 조사한 뒤 반복 적용 가능한 마이그레이션을 작성한다.

## 검증

빈 데이터베이스 배포, 기존 데이터가 있는 데이터베이스 업그레이드, Prisma Client 생성, 중복 키와 외래키 실패를 확인한다. 운영 데이터 삭제 가능성이 있는 변경은 적용 전에 사용자에게 알린다.
