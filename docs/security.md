# 보안 정책

## 보호 대상

비밀번호, 세션 비밀키, eBay·Shopify·R2·포카마켓 연결정보, 구매자 정보, 주문 원본, 내부 원가와 재고는 외부 비공개 정보다. 외부 공개가 허용되는 것은 판매용으로 승인된 상품 이미지와 판매 채널에 게시하기로 한 상품 정보뿐이다.

## 로그인과 세션

사용자는 로그인 ID와 비밀번호를 제출하고, 서버는 저장된 해시와 비교한 뒤 7일 만료의 서명된 HTTP 전용 쿠키를 발급한다. 잘못된 자격증명은 세션을 만들지 않는다. 같은 계정 또는 접속지에서 10분 동안 5회 실패하면 15분 동안 로그인을 차단하고 관리자에게 실패·차단 기록을 보여준다. 서명 검증 실패, 만료, 존재하지 않는 사용자, 지원하지 않는 역할은 모두 로그아웃 상태로 취급한다. 운영 환경의 쿠키는 HTTPS에서만 전송한다.

계정 생성과 비밀번호 재설정은 관리자가 수행한다. 직원이 퇴사하거나 업무에서 제외되면 계정을 즉시 비활성화하고 기존 세션을 무효화한다. 휴대전화 분실 또는 포카마켓·로컬 이미지 작업 토큰 노출이 의심되면 해당 토큰을 즉시 폐기하고 새 값으로 교체한다. eBay·Shopify 연결은 담당자 변경 또는 노출 의심 시 기존 승인을 폐기하고 다시 연결한다. 비밀키 교체 시 기존 세션 또는 암호화된 외부 토큰을 더 이상 읽지 못할 수 있으므로, 세션 비밀키 교체와 외부 토큰 암호화 키 교체를 같은 절차로 취급하면 안 된다.

## 권한

| 사용자 | 허용 | 금지 |
|---|---|---|
| 관리자 | 주문·상품·재고·판매 계정·등록 초안·가격 설정·구매 요청·이미지 관리 | 확인 없는 포카마켓 결제, 승인 없는 이미지 자동 채택 |
| 작업자 | 로그인, 배정된 이미지 조회·처리·검토 결과 제출 | 주문·구매자·가격·원가·재고·eBay·Shopify 계정 접근 |
| 로컬 작업 프로그램 | 전용 토큰으로 배정 작업 조회와 처리 결과 보고 | 관리자 세션 사용, 다른 업무 데이터 조회, 결제 인증 우회 |
| 미로그인 사용자 | 로그인과 외부 서비스 검증에 필요한 공개 경로 | 그 밖의 모든 데이터 조회·변경 |

화면에서 버튼을 숨기는 것만으로 권한을 보장하지 않는다. 모든 데이터 조회·변경 요청의 서버 진입점에서 역할을 다시 확인한다.

## 자격증명과 민감정보

- 비밀번호는 해시로 저장하고 원문을 기록하지 않는다. 외부 OAuth 토큰은 인증된 암호화 방식으로 저장한다.
- `.env`, 휴대전화 연결 설정, 전용 토큰과 실제 API 키는 저장소에 커밋하지 않는다. 예제 파일에는 가짜 값만 둔다.
- 포카마켓 통신을 분석할 때는 본인이 소유·관리하는 기기와 계정만 사용한다. 서비스 이용 조건과 계정 보안에 문제가 없는 범위에서만 진행한다.
- 포카마켓 원본 통신 기록, 세션 토큰, 결제정보를 배포 서버에 저장하지 않는다. 상품번호, 표시 가격, 판매 가능 상태, 확인 시각처럼 업무에 필요한 최소 결과만 저장한다.
- 로그에는 토큰, 쿠키, 비밀번호, 구매자 주소, 결제정보를 남기지 않는다. 외부 오류를 저장할 때도 비밀값을 제거한다.

## 기록과 삭제

재고 변경, 상품 연결, 이미지 승인·거절, 포카마켓 구매 요청과 상태 변경, eBay·Shopify 게시 결과를 추적 가능하게 기록한다. 로그인 실패·일시 차단·권한 거부·계정 비활성화·작업 토큰 폐기도 기록해야 하지만 현재 구현에는 이 감사 기록이 없으므로 운영 확대 전에 추가해야 한다. 운영 데이터나 사진 삭제는 관리자가 대상과 영향을 확인한 요청에서만 수행하며, 연쇄 삭제 전에 주문·재고 이력 보존 여부를 확인한다. 보존 기간과 백업·복구 절차는 아직 정해지지 않았으므로 운영 확대 전에 결정해야 한다.
