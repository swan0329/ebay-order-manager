# 업무 규칙

## 상품과 재고

- SKU는 판매 단위를 식별한다. eBay 주문 항목은 같은 SKU로 자동 연결할 수 있으며, 확실하지 않은 연결은 사람이 상품을 선택해 확정한다.
- 사람이 확정한 연결은 이후 자동 수집이나 유사도 결과보다 우선한다. 자동 처리로 사람의 연결을 덮어쓰면 안 된다.
- 내부 재고는 실제 보유 수량의 기준이다. 포카마켓에 판매 중인 상품이 있어도 구매가 완료되어 내부 입고 처리되기 전에는 내부 재고로 계산하지 않는다.
- 입고와 취소 복구는 수량을 더하고, 출고와 주문 차감은 수량을 뺀다. 조정은 입력값을 새 수량으로 사용한다. 모든 변경은 변경 전·후 수량과 사유를 이력으로 남긴다.
- 재고는 음수가 될 수 없다. 부족하면 차감을 건너뛰고 부족 상태를 표시한다.
- 한 주문 항목은 한 번만 차감한다. 이미 차감 표시가 있으면 주문을 다시 불러오거나 차감 버튼을 다시 눌러도 수량을 바꾸지 않는다.
- 취소 주문은 차감하지 않는다. 이미 차감한 주문이 취소되면 같은 수량을 복구하고 복구 이력을 남긴다.
- 배송 완료 주문도 아직 차감되지 않았다면 차감 대상이다. 취소 상태만 차감 대상에서 제외한다.

## 포카마켓 조달

- 조달 창구는 **빠른구매**다. 1:1 거래는 성사까지 오래 걸려 주문 처리에 쓸 수 없다. 따라서 기준가와 조달 가능 수량은 모두 빠른구매 기준으로 읽는다(카드 상세 응답의 `get_collection_lowest_sell_offer_price`, `get_collection_count`). 같은 카드라도 1:1 최저가는 빠른구매가보다 훨씬 싸므로(표본 중앙값 2배, 최대 3.25배) 1:1 최저가를 기준가로 쓰면 원가를 실제보다 낮게 잡아 손해 보는 가격에 판다.
- 빠른구매 물건이 없으면 1:1에 물건이 있어도 품절로 본다. 우리 창구로는 살 수 없기 때문이다.
- eBay에 올릴 상품 파일은 관리자가 검토하고 직접 등록한다. 내부 재고가 없는 상품도 포카마켓에서 판매 중이라면 등록 후보가 될 수 있다.
- eBay 주문 뒤 내부 재고가 부족하면 관리자가 포카마켓 구매를 명시적으로 요청한다. 시스템은 주문이 들어왔다는 이유만으로 구매를 시작하면 안 된다.
- 구매 요청은 배송 대기 중인 주문, 연결된 상품, 부족한 수량에 대해서만 만든다. 포카마켓 가격이 허용 한도를 넘거나 품절이면 자동 결제하지 않고 관리자 확인 대상으로 남긴다.
- 결제 인증은 사람이 수행한다. 휴대전화 자동 조작은 상품 선택과 결제 직전까지 보조할 수 있지만 사람 확인을 우회할 수 없다.

## 가격 계산

여기서 말하는 포카마켓 상품가는 **빠른구매 최저가**다. 실제로 그 값으로 결제하기 때문이다.

가격 설정에는 포카마켓 상품가, 포카마켓 국내 배송비, 구매대행 비용, 원·달러 환율, 목표 마진율, eBay 판매수수료율, eBay 광고율을 입력한다. 해외 배송비와 별도의 환율 변동 여유분은 넣지 않는다.

`원화 원가 = 포카마켓 상품가 + 국내 배송비 + 구매대행 비용`

`달러 원가 = 원화 원가 ÷ 적용 환율`

`권장 eBay 판매가 = 달러 원가 × (1 + 목표 마진율) ÷ (1 - eBay 판매수수료율 - eBay 광고율)`

목표 마진율은 달러 원가에 대한 비율이다. 수수료율과 광고율의 합이 100% 이상이면 계산을 거부한다. 환율이 없거나 0 이하인 경우, 비용 중 음수가 있는 경우에도 계산하지 않는다. 반올림 단위와 최소 판매가는 아직 확정되지 않았으므로 구현 전에 관리자가 결정해야 한다.

계산 결과는 상품 업로드 자료의 권장 가격으로 제공한다. 계산만으로 eBay 가격을 자동 변경하거나 상품을 자동 게시하면 안 된다.

## 이미지

- 자동 매칭, 워터마크 제거, 배경·크기 조정 결과는 미리보기일 뿐이다. 사람이 승인해야 상품의 최종 이미지가 된다.
- 승인 전 원본 이미지와 이전 이미지 주소를 보존한다. 거절된 결과는 상품 이미지를 바꾸지 않는다.
- 작업자는 자신에게 배정된 이미지 작업만 처리한다. 상품 가격·재고·주문·판매 채널 정보는 이미지 작업에 필요하지 않다.
- 현재 최우선 품질 목표는 포카마켓 이미지의 워터마크를 카드 고유 무늬를 훼손하지 않고 제거하는 것이다. 제거 흔적, 글자 잔상, 카드 테두리 손상은 승인 실패 사유다.
