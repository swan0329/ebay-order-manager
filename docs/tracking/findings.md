# 해결되지 않은 문제

## 워터마크 제거 품질

포카마켓 이미지에 워터마크가 있는 조건에서 제거 흔적이나 카드 무늬 훼손이 발생한다. 승인 가능한 판매 이미지를 안정적으로 만들지 못해 이미지 업무의 처리량과 품질에 직접 영향을 준다. 이번 작업은 문서 정리 범위라 모델·마스크·후처리 비교를 실행하지 않았다. 대표 실패 이미지를 고정 세트로 만들고 제거 방식별 결과를 사람 평가와 함께 비교해야 한다.

## 포카마켓 최신 정보 수집 방식

공개적으로 확인되는 공식 개발용 API가 없어 상품·가격·판매 상태를 안정적으로 최신화할 계약이 없다. 화면 자동화는 변경에 약하고, 통신 분석은 이용 조건과 계정 보안을 확인해야 한다. 외부 제공 여부를 이 작업에서 확정할 수 없었다. 포카마켓에 제휴·내보내기 수단을 문의하고, 없다면 본인 기기의 정상 통신에서 최소 필드만 추출하는 검증용 연결을 설계한다.

## 런타임 데이터 구조 변경

AI 이미지와 포카마켓 구매 등 일부 기능은 요청 처리 중 테이블이나 인덱스를 만든다. 동시에 요청되거나 배포 권한이 제한되면 기능이 실패할 수 있고 데이터 구조의 실제 버전을 추적하기 어렵다. 광범위한 미커밋 작업과 운영 데이터 호환성 때문에 지금 즉시 제거할 수 없다. 모든 런타임 SQL을 목록화하고 데이터 보존 마이그레이션으로 옮겨야 한다.

## 손상된 한글

기존 README와 여러 소스 메시지에서 한글이 깨져 있다. 사용자 화면과 오류 진단의 의미가 훼손될 수 있다. 원래 문구를 코드만으로 확정할 수 없어 일괄 복원하지 않았다. 실제 화면과 업무 의미를 기준으로 파일별 복원 및 UTF-8 검증이 필요하다.

## 운영 복구 정책

데이터 보존 기간, 정기 백업, 복구 시험 절차가 정해지지 않았다. 주문·재고·구매 기록이 손상되면 사업 운영을 복구할 기준이 없다. 운영 책임자의 정책 결정이 필요하므로 이번 작업에서 임의로 정하지 않았다.

## 환경설정 예제 누락

`.env.example`을 복사한 조건에서 Shopify, 포카마켓 Android 연결, 로컬 AI, Cloudflare 관리 작업에 필요한 여러 변수가 빠져 있다. 선택 기능을 켜는 개발자와 운영자가 실행 중 오류가 난 뒤에야 누락을 알게 된다. 이번 작업은 문서만 정리하며 기존 코드·설정 파일을 변경하지 않는 범위라 예제 파일을 수정하지 않았다. 각 기능의 필수·선택 값을 실제 운영 환경과 대조한 뒤 비밀값이 없는 설명용 항목을 `.env.example`에 추가해야 한다.
