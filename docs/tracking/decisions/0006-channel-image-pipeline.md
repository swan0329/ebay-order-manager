# 판매채널 이미지 파이프라인을 하나로 고정한다

## 결정

eBay와 Shopify는 채널별 이미지 파이프라인을 만들지 않는다. 모든 판매채널 이미지는 다음 단계를 반드시 따른다.

1. 촬영본 연결 이미지 또는 사람이 승인한 이미지 작업 결과만 등록 원본이 될 수 있다.
2. 등록 원본에 계정의 `워터마크 설정`을 적용해 공용 채널 이미지를 만든다.
3. 원본 URL, 로고, 워터마크 설정이 같으면 기존 R2 공용 이미지 URL을 재사용한다.
4. eBay, Shopify, 옵션 대표 썸네일은 이 설정과 공용 이미지 자산을 사용한다.

자동 매칭 후보, 검색 후보, 검수 전 결과, 이전 갤러리의 추가 URL, 외부 채널에서 역조회한 미디어는 등록 원본으로 승격할 수 없다. 앞면 이외의 이미지는 해당 면을 사람이 별도로 승인했다는 근거가 생기기 전까지 자동 게시하지 않는다.

## 검증 원칙

Shopify Admin API가 반환한 미디어는 `연결된 Shopify 관리 상품의 미디어`일 뿐이다. 공개 상품 페이지에서 실제 노출을 확인하지 않았다면 `실제 게시 이미지`라고 표현하거나 다른 채널의 원본으로 사용하면 안 된다. eBay도 외부 API 저장 상태와 구매자 화면 노출 상태를 구분한다.

## 이유

채널마다 워터마크를 다시 만들면 설정과 데이터가 어긋나고 중복 자산이 생긴다. 기존 갤러리나 후보 목록을 승인 결과 뒤에 덧붙이면 사람이 작업하지 않은 이미지가 게시될 수 있다. 따라서 승인 원본, 공용 파생 이미지, 외부 노출 검증을 서로 다른 단계로 유지한다.
