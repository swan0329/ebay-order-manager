# 포카마켓 정보 수집 경계

## 배경

내부 재고가 없는 eBay 판매 상품의 조달 가능성과 가격을 판단하려면 포카마켓의 최신 상품번호·가격·판매 상태가 필요하지만 공개 개발용 API를 확인하지 못했다.

## 결정

먼저 포카마켓에 제휴 또는 데이터 내보내기 수단을 문의한다. 제공 수단이 없으면 본인이 소유·관리하는 기기와 계정의 정상 통신을 분석해 상품번호, 가격, 판매 상태, 확인 시각만 추출한다. 서비스 이용 조건과 계정 보안에 문제가 없는지 확인된 경우에만 `mitmproxy` 같은 도구를 사용한다.

## 고려한 대안

화면 자동 조작만으로 전체 데이터를 수집하면 통신 내용을 다루지 않지만 화면 구조와 좌표 변경에 지나치게 약하다. 제3자 비공식 데이터 판매처는 출처·정확성·사용 권리를 검증할 수 없어 선택하지 않았다. 차단 회피나 다른 이용자의 통신 수집은 보안과 이용 조건을 위반할 수 있어 허용하지 않는다.

## 결과

원본 통신 기록, 세션·결제정보는 서버에 보관할 수 없다. 수집 실패는 기존 값을 무조건 삭제하지 않고 마지막 확인 시각과 실패 상태로 드러내야 한다. 포카마켓이 공식 수단을 제공하면 비공식 연결보다 우선한다.
