# 로그인 제한과 접근 회수

## 배경

내부 직원만 사용하는 시스템이지만 주문·원가·판매 계정과 결제 보조 기능을 다룬다. 반복 비밀번호 시도, 퇴사한 직원, 분실한 Android 기기 또는 노출된 작업 토큰을 계속 허용하면 내부 전용이라는 경계가 무너진다.

## 결정

같은 계정 또는 접속지에서 10분 동안 로그인에 5회 실패하면 15분 차단한다. 직원이 퇴사하거나 업무에서 제외되면 계정을 즉시 비활성화하고 세션을 무효화한다. 기기 분실 또는 포카마켓·로컬 이미지 토큰 노출이 의심되면 즉시 폐기·교체한다. eBay·Shopify 연결은 담당자 변경 또는 노출 의심 시 폐기하고 다시 승인한다.

## 고려한 대안

제한 없는 로그인은 내부 사용이 편하지만 유출된 계정에 대한 반복 시도를 막지 못한다. 관리자 수동 해제 전까지 영구 잠금은 야간 운영 중 정상 사용자를 오래 막을 수 있어 선택하지 않았다. 모든 외부 토큰의 정기 강제 교체는 운영 중단 위험이 커서 사고·담당자 변경 시 교체로 정했다.

## 결과

로그인 실패 횟수·차단 만료·계정 활성 상태·세션 무효화 기준과 토큰 폐기 시각을 저장해야 한다. 이 기능이 구현되기 전에는 문서의 정책만으로 차단이나 회수가 작동한다고 간주할 수 없다.
