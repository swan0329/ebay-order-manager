# 주요 선택

- `0001-human-confirmation.md`: 구매·이미지·판매가 반영은 사람이 최종 확인한다.
- `0002-pocamarket-data-collection.md`: 포카마켓 정보는 본인 기기의 정상 통신에서 최소한으로 수집한다.
- `0003-margin-based-price.md`: 포카마켓 원가와 설정된 비용·수수료·목표 마진으로 권장 eBay 가격을 계산한다.
- `0004-access-revocation.md`: 반복 로그인 실패를 제한하고 직원·기기 자격증명을 즉시 회수한다.
- `0005-feature-branches.md`: 기능별 브랜치와 목적별 커밋을 사용한다.
