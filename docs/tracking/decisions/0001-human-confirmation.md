# 사람의 최종 확인 유지

## 배경

자동 이미지 처리는 카드 무늬를 훼손할 수 있고, 포카마켓 구매는 실제 결제를 만들며, 계산 가격은 판매 손익에 직접 영향을 준다.

## 결정

시스템은 후보 생성과 반복 조작을 자동화하되 포카마켓 결제 인증, 이미지 채택, 계산 가격의 eBay 반영은 사람이 명시적으로 확인한다.

## 고려한 대안

완전 자동화는 처리 속도가 빠르지만 잘못된 구매·손상 이미지·손실 가격을 사람 확인 없이 확정할 위험 때문에 선택하지 않았다. 모든 단계를 수동으로 하는 방식은 안전하지만 대량 상품 처리의 반복 작업을 줄일 수 없어 선택하지 않았다.

## 결과

승인 대기 상태와 승인 주체를 저장해야 한다. 배치 작업은 사람 확인을 생략할 수 없으며, 사람이 자리를 비운 동안 결제·게시·최종 이미지 교체를 완료하는 기능은 허용되지 않는다.
